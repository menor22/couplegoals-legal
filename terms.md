## 3. How CoupleGoals works

CoupleGoals helps couples build shared habits and track meaningful moments together. The App lets you and your paired partner:

- Set and track shared and individual challenges (habits).
- Create shared and personal to-dos.
- Maintain a shared agenda of events.
- React to each other's progress with reactions called "Sparks."
- See your partner's activity in real time.

Pairing requires both partners to install the App, create accounts, and accept the pairing invitation. Once paired, certain data is shared between both partners as described in our Privacy Policy.
